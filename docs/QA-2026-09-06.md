# v2.34.0 遊戲更新與測試紀錄

日期：2026-09-06。基準：`54da460`（2026-05-01，v2.33.0）。本次為本機測試與功能分支更新，正式 GitHub Pages 仍由 main 發布。

## 玩家會看到的更新

新增四個全部開放的探索關卡：彈跳花園、綠洲尋寶、極光快遞、月光鐘樓。每關三顆寶石，通關、收齊寶石、不失去生命各得一星。保留最快時間、最高星數與通關次數，可重玩或直接前往下一站。各關使用彈簧、階梯、水平移動浮台、升降台和披風，並保留較容易通行的下方路線。原有四個世界與無盡模式仍可選擇。

選單支援鍵盤；觸控加入蹲下與衝刺，支援同時按住方向和跳躍。暫停可回選單、查看成就、重看教學。視窗失焦自動暫停。

- Chrome 真實遊戲實例載入 `scripts/browser-suite.js`：54 通過、0 失敗。涵蓋移動、二段跳、衝刺、蹲下、8 類能力、9 類問號磚塊、9 類敵人、彈射物、披風／牆跳、踩踏、生命／重生、檢查點、獎勵房、成就、四世界 Boss 通關／解鎖、無盡延續與物件數上限。

- 真實 PWA：`127.0.0.1:8000/?pwa=1` 安裝成功，active 狀態為 activated，116 筆靜態快取。關閉本機伺服器後，一般重新整理仍可進入選單、啟動彈跳花園，遊戲持續推進。強制略過快取的重新整理會繞過 SW，不視為離線開啟方式。

## 可重現方式

1. 專案根目錄執行 `node server.js`，開啟 `http://localhost:8000/`。
2. 執行上述 Node 測試指令。
3. 瀏覽器進入任一關卡後，在開發者工具執行 `await (await import('./scripts/browser-suite.js')).runSuite(window.game)`。
4. 場景測試會暫時更改遊戲狀態，並在 finally 還原該本機 origin 的存檔；測完重新整理恢復正常遊玩。

下一輪可先把同一模型渲染為透明 sprite 動畫格，固定底部錨點與碰撞盒，接入單一探索關卡驗證。關卡設計可逐步改為資料描述，將機關、敵人、裝飾與獎勵獨立配置。自由鏡頭 3D／GLB 應另做小型原型，再評估行動裝置效能與操作，不直接改寫既有遊戲。
